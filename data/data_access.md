# Доступ к данным

Полный набор данных о дорожно-транспортных происшествиях не размещен в репозитории из-за большого размера файлов.

Данные доступны во внешнем хранилище:
https://disk.yandex.ru/d/uiVaX7aTbdiuNA

## Состав данных

- `data_traffic_accidents_raw_csv.zip` — архив с исходным набором данных о дорожно-транспортных происшествиях;
- `accidents_ed.csv` — обработанный набор данных, использованный для анализа в Jupyter Notebook.

## Источник данных

В проекте использовались открытые данные о дорожно-транспортных происшествиях:
координаты ДТП, сведения об участниках, пострадавших, времени происшествия, погодных условиях и состоянии дорожного покрытия.
Источник данных — проект «Если быть точным».

## Примечание

В репозитории размещены код обработки, графики, метаданные и пояснительная записка. 
Полные табличные данные доступны по внешней ссылке, так как размер файлов превышает удобный лимит для загрузки через GitHub.
